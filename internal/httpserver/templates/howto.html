email-mcp — MCP endpoint for your mail account

The MCP endpoint URL is fixed: {{.Endpoint}} (POST {{.Endpoint | printf "%s"}}). Authentication is OAuth 2.0 only: email-mcp runs its own authorization server, and the access token it issues carries your whole account, so the client only needs a single Authorization: Bearer header.

  1. Register your MCP client once (RFC 7591): POST {{.Register}} with {"redirect_uris":["..."]}.
  2. Start the authorization flow: GET {{.Authorize}}?client_id=...&redirect_uri=...&state=...&scope=email&code_challenge=...&code_challenge_method=S256 — the consent form asks for your mail account (email + password/app password, optional IMAP/SMTP overrides; empty servers are auto-discovered via DNS).
  3. Exchange the returned code at POST {{.Token}} (grant authorization_code + PKCE verifier) for an access token and a refresh token.
  4. Configure your client with the fixed endpoint and Authorization: Bearer <access token>.

Machine-readable discovery for OAuth-aware clients: {{.ResourceMD}} → {{.ServerMD}}.
